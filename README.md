# Huawei MTK Bootloader Unlock Tool 🔓

![Version](https://img.shields.io/badge/version-2.0-blue)
![Platform](https://img.shields.io/badge/platform-MediaTek-orange)
![License](https://img.shields.io/badge/license-MIT-green)
![GitHub](https://img.shields.io/badge/GitHub-yazsalaq-181717?logo=github)

> **أداة لفتح البوت لودر (Bootloader Unlock) لهواتف Huawei التي تعمل بمعالجات MediaTek، عن طريق حقن بايلود مخصص في ذاكرة الجهاز.**

---

## 📌 ما هي هذه الأداة؟

هذه الأداة تُستخدم لـ:

| # | الميزة | الوصف |
|---|--------|-------|
| ✅ | **فتح البوت لودر** | لهواتف Huawei (MTK) |
| ✅ | **حقن بايلود** | في ذاكرة الجهاز لتجاوز الحماية |
| ✅ | **تثبيت ريكفري مخصص** | تثبيت TWRP |
| ✅ | **الحصول على صلاحيات الروت** | Root Access |
| ✅ | **قراءة وكتابة على الـ Bootloader** | تعديل مباشر على البوت لودر |

---
